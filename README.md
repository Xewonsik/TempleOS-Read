# TempleOS
TempleOS is a unique, 64-bit operating system created entirely by a single American programmer, Terry A. Davis. Davis spent over a decade building it from scratch. Because he suffered from severe schizophrenia, he deeply believed he was building a digital "Third Temple" under the direct instruction of God.
While the backstory is tragic, tech enthusiasts view TempleOS as a brilliant piece of "outsider art" in computer science. Davis wrote his own kernel, compiler, graphics engine, and games completely alone.

## ⚒️ Key Technical Features ⚒️

Davis designed TempleOS to be fast and simple. He intentionally kept the specifications limited, claiming that God ordered these exact rules:

0. HolyC Language: The entire OS is written in HolyC, a custom version of C/C++ created by Davis. It compiles instantly "on the fly" (JIT), letting you run code directly inside the terminal.
1. Retro Graphics & Sound: The system is strictly limited to a 640×480 resolution, a 16-color VGA palette, and a simple 8-bit audio system.
2. Full Access (Ring 0): There is no memory protection or user permissions. All programs have direct access to the hardware. It is incredibly fast, but a single typo or crash in a program will freeze the entire system.
3. DolDoc System: A unique text format where code, text, graphics, and even spinning 3D models can coexist in the same document or terminal window.
5. No Internet Support: The OS has absolutely no networking capability. Davis believed this kept his "temple" pure and simple.

## ☦️ The Religious Programs ☦️

The operating system includes several built-in tools meant for spiritual purposes:

1. The Oracle (AfterEgypt): A random word and number generator. Davis believed that God could use this digital randomness to speak to humans, similar to a digital Ouija board.
2. Biblical Games: Simple programs, including a flight simulator and a game where you guide Moses through the desert.

Today, you can easily run TempleOS on modern computers using virtual machine software like VirtualBox or QEMU by downloading the official ISO from templeos.org.
